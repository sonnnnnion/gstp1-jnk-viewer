# GSTP1–JNK Research Viewer

Companion page to the poster *Computational Design and Structural Validation of
JNK Constructs for Investigating the GSTP1–JNK Interaction* (Michael A.
Bockstaller, Carnegie Mellon University — research conducted in the Rule Lab,
Department of Biological Sciences).

**Live:** https://sonnnnnion.github.io/gstp1-jnk-viewer/

`index.html` is one self-contained file — no build step, no dependencies, no
network access at runtime. Clone it and open it, or download the single file
and double-click it offline.

Shows the AlphaFold confidence and chain-pair ipTM results for seven JNK
constructs, an interactive Cα backbone trace, and the explicit-solvent
molecular dynamics stability results (4 replicas × 5 ns per construct).

Values are produced by the project's analysis pipeline and are reproduced here
unchanged. The longer 4 × 50 ns runs are complete but still being analysed and
are deliberately not shown.
